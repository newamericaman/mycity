# 🚀 پنل 3x-ui (سنایی) روی Railway — نسخه v3.6.0

دیپلوی آماده و بررسی‌شده پنل **3x-ui** (پنل معروف سنایی — MHSanaei) روی **Railway** با یک پورت واحد.
- باینری **رسمی v3.6.0** (ریلیز ۲۰۲۶-۰۷-۳۰) — شامل xray داخلی، بدون هیچ کد دست‌کاری‌شده
- یک دامنه، یک پورت: پنل + سابسکریپشن + اینباندها همه با هم

## 🧭 معماری (در یک نگاه)

```
اینترنت → https://دامنه.up.railway.app (پورت 3000)
              │
              ▼ nginx
   /managepanel/  → پنل وب (پورت داخلی 2053)
   /sub/          → سابسکریپشن (پورت داخلی 2096)
   /              → اینباند VLESS/WS (پورت داخلی 8080)
   /in1 … /in9    → اینباندهای اضافه (پورت‌های 8081 تا 8089)
```

## 📦 فایل‌های پکیج

| فایل | نقش |
|---|---|
| `Dockerfile` | Alpine + باینری رسمی 3x-ui + nginx (پورت 3000) |
| `start.sh` | تنظیم پنل (2053 + /managepanel/) + ساخت ادمین اولیه + اجرا |
| `nginx.conf.template` | مسیربندی تک‌پورت (پنل/ساب/اینباندها) |
| `railway.toml` | تنظیمات بیلد و ری‌استارت خودکار |
| `.env.example` | نمونه متغیرها (اختیاری) |

# 📖 آموزش گام‌به‌گام

## گام ۱ — ریپوی گیت‌هاب بسازید
1. وارد [github.com](https://github.com) شوید
2. **New repository** → نام مثلاً `3xui-railway` → **Private** (بهتره) → **Create repository**

## گام ۲ — فایل‌ها را آپلود کنید
1. توی ریپوی تازه، **Add file → Upload files**
2. این ۵ فایل را بکشید و رها کنید: `Dockerfile`، `start.sh`، `nginx.conf.template`، `railway.toml`، `.env.example`
3. **Commit changes** بزنید

## گام ۳ — در Railway دیپلوی کنید
1. وارد [railway.app](https://railway.app) شوید
2. **New Project → Deploy from GitHub repo** → ریپوی خودتان را انتخاب کنید
3. Railway خودش Dockerfile را می‌بیند و بیلد می‌کند (چند دقیقه — دانلود باینری ~76MB)

## گام ۴ — متغیرها (اختیاری ولی توصیه‌شده)
**Settings → Variables** اضافه کنید:
| Key | Value |
|---|---|
| `XUI_USERNAME` | `admin` |
| `XUI_PASSWORD` | یک پسورد خیلی قوی (مثلاً `X#9kPq!Rz2vLm7`) |

> این‌ها فقط در **اولین اجرا** (زمان ساخت دیتابیس) اعمال می‌شوند.
> اگر ست نکنید، ورود با **admin / admin** است — که خطرناکه چون پنل روی اینترنت عمومیه!

## گام ۵ — Volume (خیلی مهم! ⚠️)
**Settings → Volumes → New Volume** → مسیر mount: **`/etc/x-ui`**

> بدون این، بعد از هر دیپلوی/ری‌استارت، **همه کاربران و تنظیمات پاک می‌شوند**! (دیتابیس پنل اینجاست)

## گام ۶ — دامنه (پورت 3000!)
**Settings → Networking → Generate Service Domain** → توی پنجره، پورت را وارد کنید:
```
3000
```
> ⚠️ **عدد 3000 خیلی مهمه** — nginx ما دقیقاً روی همین پورت گوش می‌ده. عدد دیگه‌ای بزنی دامنه جواب نمی‌ده.

## گام ۷ — ورود به پنل
آدرس پنل:
```
https://دامنه‌ی-شما.up.railway.app/managepanel/
```
یوزر/پسورد: همان‌هایی که در گام ۴ گذاشتید (یا admin/admin).
**بلافاصله** از منوی **تنظیمات پنل → تغییر رمز** پسورد را عوض کنید.

## گام ۸ — ساخت اینباند (کانفیگ)
1. از منوی **Inbounds** → **Add Inbound**
2. با این مقادیر دقیق:

| فیلد | مقدار |
|---|---|
| Protocol | `VLESS` |
| Listen Port | **`8080`** ← نباید عوض بشه |
| Listen IP | خالی (یا `0.0.0.0`) |
| Network | `ws` |
| Security | `none` |
| Path | مثلاً `/cdn` (هر چیزی می‌خواید) |

3. **Save** بزنید
4. تب **Clients** → **Add Client** (UUID خودکار ساخته می‌شه) → دوباره **Save**

## گام ۹ — لینک کلاینت
- کنار هر کلاینت، آیکون QR/لینک را بزنید → لینک `vless://…` را کپی کنید
- فرمت دستی (اگر بخواید خودتان بسازید):

```
vless://UUID@دامنه.up.railway.app:443?encryption=none&security=tls&sni=دامنه.up.railway.app&fp=chrome&type=ws&host=دامنه.up.railway.app&path=%2Fcdn#MyConfig
```

> ⚠️ حتماً `sni` و `host` را همون دامنه بگذارید و `path` را با Path اینباند هماهنگ کنید.

- در v2rayNG / Streisand / Hiddify: **import from clipboard** → وصل شوید ✅

## گام ۱۰ — اینباندهای بیشتر (اختیاری)
nginx مسیرهای `/in1` تا `/in9` را از قبل به پورت‌های `8081` تا `8089` وصل کرده. برای اینباند دوم:
- پورت: `8081` ، Path: `/in1`
- (یا چند اینباند با Path های مختلف روی همان پورت `8080` — اشکالی نداره)

# 📡 سابسکریپشن
سرویس ساب 3x-ui به‌صورت پیش‌فرض روشنه (پورت داخلی 2096). لینک ساب را از پنل کپی کنید؛
اگر شامل `:2096` بود، به این شکل اصلاحش کنید:
```
https://دامنه.up.railway.app/sub/TOKEN
```

# 🔧 عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| «Application failed to respond» | در Generate Service Domain عدد **3000** را وارد کرده‌اید؟ |
| بعد از دیپلوی جدید، کاربران پاک شدند | Volume روی `/etc/x-ui` نساخته‌اید (گام ۵) |
| لوپ ری‌استارت | لاگ‌ها را ببینید (View Logs) — معمولاً مربوط به Volume یا پورت است |
| نمی‌تونم وارد بشم | admin/admin را امتحان کنید؛ اگر قبلاً عوضش کرده بودید و یادتون نیست: `XUI_USERNAME`/`XUI_PASSWORD` را ست کنید، Volume را موقتاً بردارید (دیتابیس پاک می‌شه) و دوباره دیپلوی کنید |
| کانفیگ وصل نمی‌شه | اینباند روی پورت **8080** و Network=**ws** ساخته‌اید؟ `path` در لینک با Path اینباند یکی هست؟ |
| پنل بالا اومد ولی صفحه‌اش خرابه | آدرس را با `/managepanel/` در انتها باز کنید |

# 🔒 نکات امنیتی
- **رمز پیش‌فرض admin/admin را حتماً عوض کنید** — پنل روی اینترنت بازه و ربات‌ها مدام اسکن می‌کنن
- دو مرحله‌ای (2FA) را از تنظیمات پنل فعال کنید
- ریپوی گیت‌هاب را **Private** نگه دارید (شامل پسوردها نمی‌شه، ولی امن‌تره)
- پسوردها را توی فایل نذارید — فقط توی Variables ریلوی

# 🔄 آپدیت نسخه
برای آپدیت به نسخه جدیدتر 3x-ui: در `Dockerfile` مقدار `ARG XUI_VERSION=v3.6.0` را عوض کنید و دوباره دیپلوی کنید. (دیتابیس روی Volume می‌مونه و از بین نمی‌ره)
